38. Which statement about transparency, interpretability, and explainability is MOST accurate?

A
Interpretability reveals inner mechanisms; explainability describes behavior from inputs/outputs

B
Explainability requires full access to model weights and gradients

C
Transparency eliminates all model security risks

D
Deep neural nets are always fully interpretable

A
Interpretability reveals inner mechanisms; explainability describes behavior from inputs/outputs

Correct. Interpretability is white-box; explainability can be model-agnostic via output analysis.

B
Explainability requires full access to model weights and gradients

Incorrect. Explainability can be performed as a black-box analysis.

C
Transparency eliminates all model security risks

Incorrect. Higher transparency can increase attack surface (e.g., reverse engineering).

D
Deep neural nets are always fully interpretable

Incorrect. DNNs are typically less interpretable than simpler models.


39. A data science lead wants to know which features most influenced an individual prediction.

Which technique is MOST appropriate?

A
Shapley-value–based feature attributions

B
Partial dependence plots

C
Confusion matrix

D
Receiver operating characteristic curve

A
Shapley-value–based feature attributions

Correct. Shapley values provide local (and global) attributions for feature influence.

B
Partial dependence plots

Incorrect. PDPs show average effect of a feature across the dataset, not local per-instance attributions.

C
Confusion matrix

Incorrect. Summarizes classification outcomes, not feature influence.

D
Receiver operating characteristic curve

Incorrect. ROC characterizes tradeoff across thresholds, not feature contributions.
