13. Which statement BEST describes embeddings in language models?

A
Embeddings encode the semantic meaning of tokens in a high-dimensional vector space

B
Embeddings primarily reduce file size for model checkpoints

C
Embeddings encrypt tokens so models can decode them securely at inference

D
Embeddings assign hard grammar rules to tokens to enforce syntax

A
Embeddings encode the semantic meaning of tokens in a high-dimensional vector space

Correct. Embeddings are numerical vector representations that capture semantic meaning and relationships; nearby vectors indicate similar meaning.

B
Embeddings primarily reduce file size for model checkpoints

Incorrect. Compression is not the purpose of embeddings; they represent meaning for computation.

C
Embeddings encrypt tokens so models can decode them securely at inference

Incorrect. Embeddings are not an encryption scheme.

D
Embeddings assign hard grammar rules to tokens to enforce syntax

Incorrect. Grammar constraints are not encoded as hard rules by embeddings.


14. What is the PRIMARY role of the self-attention mechanism in transformers?

A
Weigh different parts of the input to capture long-range dependencies and context

B
Compress model parameters to reduce memory footprint during training

C
Randomize outputs to improve diversity during inference

D
Remove the need for tokenization by operating directly on raw text

A
Weigh different parts of the input to capture long-range dependencies and context

Correct. Self-attention learns which tokens to focus on when generating representations, enabling rich contextual understanding.

B
Compress model parameters to reduce memory footprint during training

Incorrect. Self-attention is not a parameter compression method.

C
Randomize outputs to improve diversity during inference

Incorrect. Sampling strategies (temperature, top-k) affect diversity, not self-attention itself.

D
Remove the need for tokenization by operating directly on raw text

Incorrect. Transformers still rely on tokenization.

16. Which statement about DIFFUSION MODELS is TRUE?

A
They learn to reverse a gradual noising process to generate high-quality outputs

B
They are trained only with labeled pairs of input and output images

C
They generally produce lower-quality images and less diversity than GANs

D
They operate only in pixel space and cannot use latent spaces

A
They learn to reverse a gradual noising process to generate high-quality outputs

Correct. Diffusion models denoise from random noise step-by-step; Stable Diffusion operates in a latent space.

B
They are trained only with labeled pairs of input and output images

Incorrect. Diffusion training does not require paired labels like supervised tasks.

C
They generally produce lower-quality images and less diversity than GANs

Incorrect. Diffusion models often achieve high quality and diversity and are more stable to train.

D
They operate only in pixel space and cannot use latent spaces

Incorrect. Stable Diffusion uses a latent space representation.

18. A team wants the model to incorporate up-to-date enterprise knowledge without retraining the model.

Which technique provides this capability with the LEAST development effort?

A
Fine-tuning on proprietary documents

B
Retrieval augmented generation (RAG)

C
Continued pre-training on unlabeled text

D
Instruction-based fine-tuning with prompt-response pairs

A
Fine-tuning on proprietary documents

Incorrect. Fine-tuning updates model weights and requires training effort.

B
Retrieval augmented generation (RAG)

Correct. RAG augments prompts with retrieved knowledge from external systems at inference, avoiding weight updates.

C
Continued pre-training on unlabeled text

Incorrect. Continued pre-training still requires training and compute.

D
Instruction-based fine-tuning with prompt-response pairs

Incorrect. Instruction tuning changes model weights to follow instructions; it does not plug in external knowledge on-the-fly.

20. Which statement BEST describes Reinforcement Learning from Human Feedback (RLHF)?

A
It trains a reward model from human preferences to align LLM outputs, then optimizes the LLM against that reward

B
It replaces tokenization by mapping sentences to rules crafted by humans

C
It disables sampling to make outputs deterministic for every input

D
It only collects human labels for supervised classification tasks

A
It trains a reward model from human preferences to align LLM outputs, then optimizes the LLM against that reward

Correct. RLHF uses preference data to train a reward model and fine-tunes the LLM to produce helpful, harmless, and honest responses.

B
It replaces tokenization by mapping sentences to rules crafted by humans

Incorrect. Tokenization still applies; RLHF is not a rules engine.

C
It disables sampling to make outputs deterministic for every input

Incorrect. RLHF is unrelated to sampling determinism.

D
It only collects human labels for supervised classification tasks

Incorrect. RLHF collects pairwise/ranked preferences to guide generative outputs, beyond simple classification labels.


21. Which statement about IN-CONTEXT LEARNING is TRUE?

A
It guides the model with examples in the prompt without updating model weights

B
It requires labeled datasets and model retraining

C
It permanently updates the model's vocabulary with new tokens

D
It disables attention to force strict rule following

A
It guides the model with examples in the prompt without updating model weights

Correct. Few-shot/one-shot prompts provide exemplars at inference time; the model uses context without weight changes.

B
It requires labeled datasets and model retraining

Incorrect. No fine-tuning is required for in-context learning.

C
It permanently updates the model's vocabulary with new tokens

Incorrect. Vocabulary is unchanged during inference.

D
It disables attention to force strict rule following

Incorrect. Attention remains central to LLM behavior.
