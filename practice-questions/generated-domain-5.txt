47. Under the AWS Shared Responsibility Model, which responsibilities belong to the CUSTOMER? (Select TWO.)

A
Physical security of data centers

B
Patching the guest operating system on EC2 instances

C
Securing the hypervisor layer

D
Configuring IAM policies with least privilege

E
Maintaining power/cooling in AWS Regions

A
Physical security of data centers

Incorrect. AWS is responsible for security OF the cloud including facilities, hardware, and regions.

B
Patching the guest operating system on EC2 instances

Correct. Customers are responsible for security IN the cloud for services like EC2, including OS patching.

C
Securing the hypervisor layer

Incorrect. AWS secures the virtualization layer.

D
Configuring IAM policies with least privilege

Correct. Customers must configure access controls and policies within their accounts.

E
Maintaining power/cooling in AWS Regions

Incorrect. AWS handles data center operations.

Use root daily for administrative tasks

Server-side encryption requires the application to encrypt data before upload

E
Service-managed keys cannot be disabled by customers
