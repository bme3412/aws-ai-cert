23. A team wants the model to show its step-by-step reasoning for complex tasks like multi-part math word problems.

Which prompting technique is MOST appropriate?

A
Zero-shot prompting

B
Chain-of-thought prompting

C
Self-consistency by sampling multiple temperatures

D
Constrained decoding with a JSON schema

A
Zero-shot prompting

Incorrect. Zero-shot can work but does not reliably elicit step-by-step reasoning.

B
Chain-of-thought prompting

Correct. Chain-of-thought encourages the model to decompose problems and show intermediate steps.

C
Self-consistency by sampling multiple temperatures

Incorrect. Sampling multiple outputs can improve final answers but is not itself a reasoning prompt.

D
Constrained decoding with a JSON schema

Incorrect. Schemas constrain output format, not reasoning traces.

Lower the temperature and ask for JSON

Provide explicit JSON schema and few-shot examples; validate responses; enforce format with structured prompting/tooling

Increase max_tokens and let the model elaborate

D
Use chain-of-thought to improve formatting

Lower the temperature and ask for JSON

Incorrect. Lower temperature helps stability but does not guarantee schema conformance.

B
Provide explicit JSON schema and few-shot examples; validate responses; enforce format with structured prompting/tooling

Correct. Showing a schema and exemplars plus validation (and function/tool calling where available) yields consistent structured outputs.

Increase max_tokens and let the model elaborate

Incorrect. More tokens does not ensure valid JSON.

D
Use chain-of-thought to improve formatting

Incorrect. CoT targets reasoning, not strict formatting.


25. A company wants responses in a consistent brand tone across long-form outputs and has a small curated set of instruction examples.

Which method is MOST appropriate to achieve this at scale?

A
Zero-shot prompting with a style instruction

B
Instruction-based fine-tuning on prompt–response pairs

C
RAG with an external knowledge base

D
Continued pre-training on unlabeled web data

A
Zero-shot prompting with a style instruction

Incorrect. Zero-shot may drift over long outputs and across prompts.

B
Instruction-based fine-tuning on prompt–response pairs

Correct. Instruction tuning aligns outputs with desired tone and behavior using paired instruction–response data.

C
RAG with an external knowledge base

Incorrect. RAG improves factual grounding, not tone alignment per se.

D
Continued pre-training on unlabeled web data

Incorrect. Unlabeled data does not encode brand tone requirements.

32. A team wants to adapt a foundation model efficiently with limited GPU budget.

Continued pre-training on generic web data

Only adjust decoding parameters (temperature, top-p)

Full fine-tuning of all model parameters

Parameter-efficient fine-tuning (e.g., LoRA/PEFT)

Only adjust decoding parameters (temperature, top-p)

(2) RAG, (1) few-shot, (3) fine-tuning

B
(1) few-shot, (2) RAG, (3) fine-tuning

(3) fine-tuning, (2) RAG, (1) few-shot

(1) few-shot, (3) fine-tuning, (2) RAG

Incorrect. Few-shot is generally less effort than building RAG.

(1) few-shot, (2) RAG, (3) fine-tuning

C
(3) fine-tuning, (2) RAG, (1) few-shot

Incorrect. Fine-tuning typically requires the most effort.

D
(1) few-shot, (3) fine-tuning, (2) RAG

Incorrect. RAG generally requires less effort than full fine-tuning while providing strong factual grounding.
